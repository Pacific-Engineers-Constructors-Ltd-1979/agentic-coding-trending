# Agentic Coding Trending

A living knowledge base tracking AI coding agents, tools, workflows, and ecosystem changes through daily research notes and weekly synthesis.

## Browse the knowledge base

- [Daily research notes](notes/daily/) — dated signals (`YYYY-MM-DD.md`)
- [Weekly trend reviews](notes/weekly/) — ISO-week synthesis (`YYYY-Www.md`)
- [Daily note template](notes/templates/daily.md) · [Weekly note template](notes/templates/weekly.md)
- [GitHub Pages landing page](index.html)

## Coverage

- Coding agents, models, and IDE/editor integrations
- New tools, capabilities, product launches, and significant changes
- Developer workflows, adoption, and evaluation
- Ecosystem developments, including standards, partnerships, and policy

## Research standards

1. Record when a development was announced separately from when it was observed. Prefer primary sources, such as official announcements, release notes, documentation, and papers; use reliable secondary reporting for context.
2. Link evidence next to each claim and include publication dates when available. Distinguish confirmed facts from analysis and speculation.
3. Explain why a signal matters to AI-assisted software development. A single launch, benchmark, or social post does not prove adoption or a lasting trend.
4. Weekly reviews compare signals with earlier notes, describe uncertainty and follow-up questions, and link the daily notes they synthesize.
5. If there are no meaningful findings or sufficient evidence, say so explicitly rather than speculating.

## Contribute

Create a daily note from the template for each research day. At the end of the week, create an ISO-week review using its template and link the relevant daily notes. Add dated corrections to outdated information while preserving useful context.

# Agentic Coding Trending

以每日研究筆記與每週整理，持續追蹤 AI 程式開發代理、工具、工作流程與生態系變化的知識庫。

## 追蹤範圍

- 程式開發代理、模型，以及 IDE／編輯器整合
- 新工具、功能、產品發布與重要變更
- 開發者工作流程、採用情況與評估方式
- 標準、合作關係、政策等生態系變化

## 研究原則

1. 分別記錄事件發生時間與研究觀察時間。優先引用官方公告、版本說明、文件和論文，並以可靠的第二手報導補充脈絡。
2. 在每項主張旁附上證據連結及可得的發布日期，並區分已確認事實、分析和推測。
3. 說明訊號對 AI 輔助軟體開發的意義；單一發布、基準測試或社群貼文不能單獨證明採用情況或長期趨勢。
4. 每週整理應比較本週與先前筆記中的訊號，指出不確定之處及待追蹤問題，並連結所整理的每日筆記。
5. 若沒有有意義的發現或足夠證據，請明確記錄，不要臆測。

## 參與方式

研究日請依範本新增每日筆記；每週結束時，使用每週範本建立 ISO 週次摘要，並連結相關每日筆記。請為過時資訊新增有日期的更正，同時保留有用脈絡。
