# Agentic Coding Trending

A bilingual, source-backed knowledge base that tracks AI coding agents, tools, workflows, and ecosystem changes, published as a content site.

## Language

**Note**:
A time-based summary of research, written in English first and Traditional Chinese second. A note is either a Daily note or a Weekly note.
_Avoid_: Post, article, entry, report

**Daily note**:
A Note that records what one day of research found, with its evidence and coverage gaps.
_Avoid_: Daily log, daily report

**Weekly note**:
A Note that synthesizes the Daily notes of one ISO week and links to each of them.
_Avoid_: Weekly digest, weekly report

**Topic**:
A thing on the watchlist that research tracks. In the first version every Topic is a GitHub repository.
_Avoid_: Tracked repo, subject, category, tag

**Signal**:
One row in a Note's Signals table: a verified change, with its Source and a Confidence.
_Avoid_: Finding, trend, news item

**Confidence**:
High, Medium, or Low rating of how well a Signal is supported by its Sources.
_Avoid_: Certainty, score

**Source**:
A cited URL with its publisher, published date, and accessed date.
_Avoid_: Reference, link, citation

**Coverage gap**:
An area a Note did not check, or a claim that remains uncertain.
_Avoid_: Limitation, TODO

**Note link**:
A relative link from one Note to another, written as a path to the Markdown file. It must point to an existing Note; a Weekly note uses Note links to cite the Daily notes it synthesizes.
_Avoid_: Cross-reference, internal link
